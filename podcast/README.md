# פודקאסט — שיטות וכלי ניהול מתקדמים

פרק לכל נושא, בשני קולות, ובסוף כל פרק שאלות לדרך עם שקט קצר לחשוב לפני התשובה.
התסריטים נכתבו מאותו חומר של הבוחן והמילון (`src/bank*.js`, `src/glossary/`), כדי שכולם יגידו אותו דבר.
הצינור הועתק מפודקאסט הקורס ניהול מערכות תובלה ושינוע, שם נבדקו הקולות, הניקוד וקצב ההפסקות.

| | |
|---|---|
| `mp3/` | קבצי השמע. מתפרסמים באתר, ואפשר גם להעתיק אותם לטלפון. |
| `index.html` | דף הנגן. נבנה מחדש בכל הרצה, מכל הקבצים שב-`mp3/`. |
| `scripts/` | התסריטים, מנוקדים. מהם נבנה השמע. |
| `scripts/plain/` | אותם תסריטים בלי ניקוד ובכתיב מלא. כאן כותבים ועורכים; אחרי עריכה מעתיקים ל-`scripts/` ומריצים `nikud.py`, כך שגם החלפות חדשות ב-`nikud-overrides.txt` נכנסות. |
| `build.py` | ממיר תסריט לקובץ שמע ובונה את דף הנגן. רשימת הפרקים המתוכננים נמצאת בו. |
| `nikud.py` | מנקד שורות חדשות בעזרת Nakdan של דיקטה. |
| `nikud-overrides.txt` | ניקוד ידני שגובר על הניקוד האוטומטי. |

## בנייה

```
cd podcast
python nikud.py 02 --map     # לפני הניקוד: מיפוי מילה->ניקוד לבדיקה, בלי לכתוב
python nikud.py 02           # מנקד את התסריט במקום
python build.py 02           # פרק בודד; דף הנגן מתעדכן תמיד
python build.py --force      # הכל מחדש
```

דורש `edge-tts` ו-`ffmpeg`. הניקוד והסינתזה מקוונים, ולכן צריך אינטרנט.
כל שורה נשמרת ב-`.cache/` לפי גיבוב של הטקסט והקול, כך ששינוי משפט אחד מסנתז שורה אחת בלבד.

## פורמט התסריט

```
# title: שם הפרק              <- קובע את שם הקובץ ואת תגית ה-ID3; בלי ניקוד
ש: שורה של המראיינת          <- קול נשי (Hila)
א: שורה של המסביר            <- קול גברי (Avri)
~4                            <- שקט של 4 שניות לפני תשובה
                              <- שורה ריקה = הפסקה קצרה
# הערה                        <- לא נקרא
```

## כללי כתיבה

- **מספרים במילים**, בלי מקפים, וגרש אסקי (`ג'`) ולא גרש עברי. בלי ראשי תיבות עם גרשיים.
- **מונחים באנגלית בתעתיק עברי**, כמו שאומרים אותם בכיתה.
- **קמץ קטן נקרא /a/.** לכן „תוכנית״ נכתבת בווי״ו וחולם ב-`nikud-overrides.txt`, ולא „תָּכְנִית״.
- **את `--map` מריצים לפני הניקוד**, כי אחריו אין בתסריט שורות שדורשות עבודה. ההחלפות בקובץ דורשות אותן אותיות בדיוק; מילה שצריכה כתיב אחר (כמו „קַיָּמוּת״) מנוקדת ביד בתוך התסריט, ו-`nikud.py` לא נוגע בה.
- **התאמות לקול** (`tts_safe` ב-`nikud.py`, רץ אוטומטית): הקול מוסיף תנועה או צליל v כשיש דגש על אות שאינה בכ״פ, ולכן „אִרְגּוּן״ נשמע „איר גאון״ ו„תּוֹמֶכֶת״ נשמע „תבומכת״. בעברית מדוברת לדגש כזה אין צליל, ולכן הוא מוסר. באותו שלב „כָּל״ הופך ל„כֹּל״, כי הקול קורא אותו „קַל״, ווי״ו כפולה נכתבת בכתיב מלא („כִּיווּנִים״).
- **יש מילים שהקול קורא נכון רק בכתיב מסוים**, ולפעמים רק בלי ניקוד בכלל („דווקא״, „ובציוד״). לכן ערך ב-`nikud-overrides.txt` יכול להיות גם המילה עצמה בלי ניקוד. „תוכנית״ נכתבת בחולם חסר, „במפורש״ בחולם מלא, ו-SWOT נכתב „סבוט״ כדי שיישמע „סווט״.
- **משפט ארוך משנה את ההגייה.** אותו משפט נשמע נכון לבד ומשובש בסוף שורה ארוכה. הגדרה חשובה עדיף לשים בשורת `א:` נפרדת.
- **בדיקת שמע**: אחרי הבנייה מתמללים את הפרק ב-faster-whisper ומשווים לתסריט. חשד בודק שוב בחיפוש קרן (beam) על קטע קצר, ואז מסנתזים כמה כתיבים של המילה במשפט קצר ובוחרים את מה שנשמע נכון. כך נמצאו כל הכללים שלמעלה.
