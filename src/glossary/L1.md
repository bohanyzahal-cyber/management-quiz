# שיעור 1 — מושגים

- **Management / ניהול** — "אין הגדרה מדויקת אחת"; ההגדרה בקורס: התהליך שמשלב תכנון, ארגון, מנהיגות ובקרה של המאמצים האנושיים להשגת יעדי הארגון (שקף 4). "הניהול הוא מקצוע".
- **Core managerial functions / ארבע פונקציות הניהול** — תכנון, ארגון, מנהיגות (הובלה) ובקרה; "מאגדים את כל התפקידים, ההגדרות והתיאוריות", ותקפים לכל מנהל בכל ארגון (שקף 6).
- **Planning / תכנון** — קביעת יעדים, כיוונים ואמצעים; הגדרת המשימות, איך ומתי; זיהוי המשאבים והתחייבות להם (שקף 7). בכיתה: "מינימום אמצעים למקסימום תפוקות", ותכנון טוב נגזר מהמשאבים.
- **Organizing / ארגון** — היכן יתקבלו ההחלטות; הקמת מחלקות והגדרות תפקיד; שיוך המשימות המתוכננות ליחידים ולקבוצות (שקף 8). בכיתה: מניעת כפל תפקידים ומשימות ש"נופלות בין הכיסאות".
- **Leading / מנהיגות, הובלה** — השפעה והכוונה של פעילות חברי הארגון לכיוון הרצוי, ועידודם להשיג את יעדי הארגון (שקף 9). בכיתה: הנעה, אינטליגנציה רגשית, "חנוך לנער על פי דרכו".
- **Controlling / בקרה** — איסוף מידע שמודד ביצועים, השוואת הביצוע בפועל למתוכנן וקביעת פעולות מתקנות (שקף 10). בכיתה: KPI, לקוח סמוי, "לא רק מספרים".
- **Organization / ארגון (כישות)** — קבוצה מתואמת של אנשים שפועלים יחד להשגת מטרות מוגדרות, שבדרך כלל אי אפשר להשיג לבד; לארגון יש מבנה, ותפקיד ההנהלה להכווין אותו למטרות (שקף 11).
- **Synergy / סינרגיה** — "אחד ועוד אחד שווה שלוש"; "הארגון הוא הסינרגיה".
- **Resources / משאבים** — אנוש, חומריים, כספיים ומידע (שקף 5). בכיתה: גם העובדים והתרבות הארגונית הם משאב.
- **Functional manager / מנהל פונקציונלי** — אחראי על פעילות ארגונית אחת בלבד (שיווק, מכירות, כספים, משאבי אנוש, ייצור); בכיתה: "מומחה תוכן", "בר-סמכא".
- **General manager / מנהל כללי** — אחראי על יחידה מורכבת (חברה, חטיבה); מתכלל, מסנכרן ומתעדף, "רואה ממעוף הציפור". לא רק המנכ"ל — גם מנהל אגף או מחלקה שתחתיו אנשי מקצוע מתחומים שונים.
- **Areas of responsibility / תחומי אחריות** — הפונקציונלי מתמקד בתחומי מומחיות טכניים; הכללי מפקח על עבודת המנהלים הפונקציונליים ואחראי לכלל פעילות היחידה (שקף 13).
- **Competencies / כשירויות** — מה שנדרש כדי לבצע את העבודה: לפונקציונלי — תקשורת, תכנון ואדמיניסטרציה, עבודת צוות וניהול עצמי; לכללי — גם כשירות אסטרטגית ואף רב-תרבותית (שקף 13).
- **Self-management / ניהול עצמי** — "סופר חשוב", במיוחד בדרג הזוטר: "אף אחד לא אומר לך מתי ללמוד למבחן".
- **Multicultural competency / כשירות רב-תרבותית** — היכולת "לקרוא תרבויות" בעולם גלובלי; עסקאות נופלות על פערי תקשורת ותרבות.
- **TEAM** — ראשי התיבות שהציעה המרצה: Together Everyone Achieves More.
- **Levels of management / דרגי הניהול** — פירמידה של לא-מנהלים, קו ראשון, ביניים ובכירים; הקורס עוסק בשלוש רמות הניהול (שקף 14). ככל שעולים הדרישות עולות, המיון קפדני יותר והתקנים מצטמצמים. אפשר לשרטט את הפירמידה לארגון כולו וגם לכל מחלקה.
- **Non-managers / לא-מנהלים** — בסיס הפירמידה: הם עושים את העבודה ופוגשים את הלקוח; "הבסיס הוא החשוב ביותר", אף שהקורס אינו עוסק בו.
- **First-line managers / מנהלי קו ראשון** — הדרג הזוטר של הניהול; בצבא: נגדים וקצינים זוטרים; בזארה: מנהלת חנות או משמרת.
- **Middle managers / מנהלי ביניים** — יותר ניסיון, סמכות, ותק ומשאבים; "עמוד השדרה" שמתווך בין הבכירים לקו הראשון; בצבא: למשל רמ"דים וסא"לים.
- **Top managers (TMT) / ההנהלה הבכירה** — Top Management Team, המונח במחקר: מנכ"ל, סמנכ"לים, CTO; "מי שבנה את האסטרטגיה".
- **Psychological safety / ביטחון פסיכולוגי** — המושג שהמרצה חקרה בדוקטורט: מנהל שמודה בכישלון מול הצוות ("אני כשלתי בניתוח הזה").
- **Emotional intelligence / אינטליגנציה רגשית** — היכולת לקרוא ולהבין אנשים ומצבים ולדעת איך לתקשר; חלק מהמנהיגות (בהרחבה בשיעור 7).
- **From managers to coaches / ממנהלים למאמנים** — מגמה בספרות: המנהל כחונך ויועץ, ולא רק כמי שמנחית הנחיות ושומר על מרחק.
- **Burnout / שחיקה** — תוצאה של ניהול בלי היכולת "לראות את האנשים"; מובילה לעזיבה.
- **Decision support / תמיכה בקבלת החלטה** — תפקיד ה-AI: הוא תומך בהחלטה אך אינו מקבל אותה; ההנעה, התגמול והתעדוף נשארים אצל המנהל — "ה-AI מאחורינו, לא לפנינו".
- **Mystery shopper / לקוח סמוי** — דוגמה לבקרה: אנשים שמתארחים במלון כאורחים רגילים ומדווחים.
- **KPI / מדדי ביצוע** — Key Performance Indicators; כלי בקרה.
- **Flat organizations / ארגונים שטוחים** — פחות רמות ופחות בירוקרטיה, ולכן תגובה מהירה יותר.
- **Centralization / ריכוזיות** — מנהל שכל החלטה עוברת דרכו יוצר אנטגוניזם וצוואר בקבוק (בהרחבה בשיעורים 5-6).
