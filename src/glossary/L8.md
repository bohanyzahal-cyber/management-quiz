# שיעור 8 — מושגים

- **Control process / תהליך הבקרה** — תהליך דינמי ושיטתי: קביעת סטנדרטים ברורים לביצועים, השוואת הביצוע בפועל לרצוי, ופעולה מתקנת (שקף 4). מטרתו ללמוד ולהשתפר מתקופה לתקופה.
- **Standards / סטנדרטים** — נקבעים לפי שלושה דברים: מה הלקוחות רוצים, מה המתחרים נותנים ומה השגנו בתקופה הקודמת (שקף 5). מי שלא עומד בסטנדרט של המתחרים "אין לו זכות קיום".
- **בקרה גלויה מול בקרה סמויה** — "הבקרה הסמויה היא הבקרה האמיתית": מבקרים שמתארחים במלון כאורחים רגילים, ניתוח שיחות בבנק.
- **Debriefing / תחקיר** — דוגמת הצבא האמריקאי (שקפים 6-7): "המילה תחקיר היא מילה להבנה וללמידה"; מביא שקיפות, למידה ארגונית וביטחון פסיכולוגי — "הארגון הלומד".
- **Benchmarking / בנצ'מרקינג** — "מושג שתצטרכו גם למבחן": השוואה בין יחידות מקבילות לפי מדדים משותפים, בשקיפות, שיוצרת תחרות בונה (מחלקות באיכילוב; אדום-צהוב-ירוק).
- **Dashboard / דשבורד** — לוח מדדים לבקרה (ניהול פרויקטים, ייצור, הזמנות, אשראי). כדאי לבנות אותו יחד עם המנהלים, כמו ב-MBO, ולבחור בו את המדדים הקריטיים.
- **Corrective action / פעולה מתקנת** — זיהוי הסטיות בביצועים, ניתוח הסטיות, ופיתוח ויישום תוכניות לתיקונן (שקף 17). לנתח לעומק את הסיבה ולתקן עוד באותו רבעון; לשלב מדד כמותי ומדד איכותני שאינם מתנגשים.
- **Inventory control / בקרת מלאי** — שלושה סוגי מלאי: מוצרים גמורים (יקר — הושקעו בו עבודה ועלויות, ויש לשלם על אחסונו), מלאי בתהליך, וחומרי גלם (זול יותר) (שקף 18).
- **Budgetary control / בקרה תקציבית** — משיטות הבקרה הנפוצות ביותר: קביעת יעדי הוצאות, מעקב והשוואה לתקציב, ושינויים לפי הצורך (שקף 19).
- **Characteristics of an effective control system / מאפייני מערכת בקרה אפקטיבית** — מידע מובן ומוצג בצורה מתאימה; מסופק למנהלים האחראים; דיווח מהיר על סטיות, רצוי עוד לפני שקרו; התמקדות בפעילויות הקריטיות, בלי ריבוי בקרות על פעילויות שוליות; מידע שאינו מושפע מגורמים לא קשורים; ועקביות עם מטרת הפעילות (שקפים 20-21).
- **Feedback control / בקרה לאחר מעשה** — מידע על ליקויים אחרי שקרו (שקף 22); נותנת תמונה מלאה, אך את מה שקרה כבר אי אפשר להשיב.
- **Concurrent control / בקרה במקביל** — מידע על ליקויים בזמן שהם קורים: מטפלים "לפני שהלקוח עוזב ולפני שהתקלה הופכת למשבר" (שקף 22). יקרה בחברות שירות, והסכנה — כשהבקרה הופכת למטרה במקום לכלי.
- **Feedforward control / בקרה מקדימה** — ניטור התשומות ולא התפוקות, כדי למנוע ליקויים לפני שיקרו (שקף 22). יקרה ומעוררת אנטגוניזם אצל ספקים, אך מונעת את רוב התקלות (אפל); צריך לשקול עלות מול תועלת.
- **Bureaucratic control / בקרה ביורוקרטית** — בקרה מלמעלה למטה באמצעות תגמולים, עונשים, מדיניות וכללים; לעיתים קרובות לא יעילה ועמידה מאוד לשינוי (שקף 23).
- **Objective control / בקרה אובייקטיבית** — מדדים נצפים של התנהגות העובדים או של התפוקות שלהם (שקף 24); כדאי לשלב את שני הסוגים.
- **Behavior control / בקרת התנהגות** — ויסות ההתנהגויות והפעולות של העובדים בעבודה (שקף 24).
- **Output control / בקרת תפוקה** — ויסות התוצאות של העובדים באמצעות תגמולים ותמריצים (שקף 24).
- **Normative control / בקרה נורמטיבית** — נוצרת ממיון קפדני של עובדים ומהתבוננות והקשבה לעובדים ותיקים (שקף 25). "בקרת DNA": הנורמות מעצבות את הארגון, ולכן נדרשים פחות נהלים (גוגל, נורדסטרום).
- **Concertive control / בקרה קונצרטיבית** — ויסות ההתנהגות וההחלטות באמצעות הערכים והאמונות של קבוצת העבודה, בקבוצות אוטונומיות (שקף 26); משל התזמורת. חיסרון: עלולה לעודד טרמפיסטים.
- **Self control / בקרה עצמית** — העובדים מבקרים את עצמם בגבולות מוגדרים, מציבים לעצמם יעדים ועוקבים אחר ההתקדמות; "בעצם ניהול עצמי" (שקף 27). "הכי חשוב": מתאימה לארגונים שטוחים ומפנה את המנהלים לאסטרטגיה.
- **תרבות חזקה כתחליף לבקרה** — "האם תרבות חזקה יכולה להחליף חלק מסוגי הבקרה? כן": היא מגדלת עובדים ומנהלים שמבקרים את עצמם.
- **שעון נוכחות** — הנוכחות אינה משקפת את התפוקה; היא רלוונטית בייצור ובתחנות דלק, ופחות בהייטק.
- **Haier's management control system / מערכת הבקרה של Haier** — הערכה יומית של עובדי המפעל, מודל ייחודי לגיוס ולקידום, עקרון 80-20, תמריצים למנהלים מצטיינים ודוח רווח והפסד חודשי לכל עובד (שקף 31).
- **80-20 management responsibility principle / עקרון 80-20** — 20% מהעובדים, המנהלים, אחראים ל-80% מתוצאות הביצועים של החברה (שקף 32).
- **Netflix control system / מערכת הבקרה של נטפליקס** — בקרה פיננסית, ניהול תוכן, תשתית טכנולוגית, תמיכת לקוחות ובקרה התנהגותית (שקף 34).
- **Hierarchical control / בקרה היררכית** — כללים ונהלים מפורטים, סמכות מלמעלה ומפקחי איכות, תגמולים חיצוניים ותרבות נוקשה (שקף 35).
- **Decentralized control / בקרה מבוזרת** — מעט כללים, הסתמכות על ערכים ועל בקרה קבוצתית ועצמית, מבנה שטוח שבו כולם מפקחים על האיכות, תגמולים חיצוניים ופנימיים ותרבות מסתגלת (שקף 35).
